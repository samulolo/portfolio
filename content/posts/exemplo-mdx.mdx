# Este post é um arquivo MDX

Este parágrafo é **Markdown normal**, escrito direto no arquivo `.mdx` — sem passar por nenhum objeto JavaScript em `lib/posts.ts`.

## O que dá pra fazer aqui

- Formatar texto em **negrito** ou _itálico_
- Criar listas como esta
- Usar `código inline`

## E também isso

O componente abaixo é um botão React de verdade, importado no topo do arquivo e usado no meio do texto. Isso é o que Markdown puro não consegue fazer:

<Counter />

Se você clicar, o contador atualiza de verdade — é interatividade real dentro do conteúdo, não só texto formatado.
